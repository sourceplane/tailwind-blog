# tailwind-blog — risks and open questions

| ID | Risk | State | Notes |
|---|---|---|---|
| TB-A | `baseline-v1` is not yet proven live | OPEN | Proven offline in Baseline CI: the offline bootstrap with the blueprint's own hooks, the stage lane's own steps in a staged job tree, the site served by `wrangler dev` and smoke-tested with the component's own command. A console bootstrap closes it |
| TB-B | Worker size | WATCH | Contentlayer compiles each post to MDX code that the pages import, so the Worker grows with the blog: 6.5 MiB raw, 1.3 MiB gzipped with the template's posts, against Workers Free's 3 MiB. Every pull request's dry run prints it |
| TB-C | Images are not optimised | ACCEPTED | `images.unoptimized`; the template's images are small. Cloudflare Images through OpenNext's `IMAGES` binding is the upgrade |
| TB-D | Next 15.5, not 16 | ACCEPTED | The template's pin; Contentlayer2's webpack plugin and pliny are built against it, and OpenNext 1.20 supports it |
| TB-E | `app/tag-data.json` is regenerated by every build | ACCEPTED | As upstream: Contentlayer writes it from the posts' tags. A post that changes the tags changes it; commit both |
| TB-F | stack-tectonic 0.19.0, not 0.20.0 | ACCEPTED | 0.20.0's lane-shared install links each job's `node_modules` out of its tree, which Next refuses |
| TB-G | The newsletter key is set by hand | ACCEPTED | A Worker secret per environment (`wrangler secret put`); no provider is a connection here, and the route is optional |
