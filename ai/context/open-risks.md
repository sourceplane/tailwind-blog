# tailwind-blog — open risks

What is not yet proven or not yet decided. The full write-up of every risk,
including the accepted and resolved ones, is
`specs/epics/tailwind-blog/risks-and-open-questions.md`; this page lists
only what is still live, so it should be short.

| ID | Risk | State | What closes it |
|---|---|---|---|
| TB-A | `baseline-v1` is not yet proven live; it is proven offline in Baseline CI (the offline bootstrap, the stage lane's own steps, the site served and smoke-tested) | OPEN | One console bootstrap from `baseline-v1` |
| TB-B | The Worker carries every post's compiled MDX: 1.3 MiB gzipped today, against the free plan's 3 MiB | WATCH | Holds while posts are a few dozen; the dry run in every pull request's lane prints the size |

Accepted, and worth knowing before you change them: TB-C (images are not
optimised), TB-D (Next 15.5, the template's), TB-E (`app/tag-data.json` is
regenerated by every build), TB-F (stack-tectonic 0.19.0).
